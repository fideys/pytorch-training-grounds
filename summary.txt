IMPORTANT PYTHON LESSONS LEARNED

Functions
---------
def something():
    ...

creates a function.

something()

runs a function.

Return values
-------------
Functions that return values:

    def get_number():
        return 42

can be used like:

    x = get_number()

Functions without return values are usually called directly:

    do_stuff()

__name__ == "__main__"
-----------------------
Used to prevent training code from running when importing the file.

Structure:

    def load_data():
        ...

    class CNN(...):
        ...

    if __name__ == "__main__":
        ...

This allows:

    from testmnist_cnn import CNN

without retraining the model.

Why CIFAR-10?
-------------
Natural progression after MNIST.

MNIST:
- 28x28
- grayscale
- digits

CIFAR-10:
- 32x32
- RGB
- real-world objects

Classes:
- airplane
- automobile
- bird
- cat
- deer
- dog
- frog
- horse
- ship
- truck

Key CNN Change
--------------
MNIST:

    nn.Conv2d(1, ...)

CIFAR:

    nn.Conv2d(3, ...)

because CIFAR images have RGB channels.

Expected Difficulty
